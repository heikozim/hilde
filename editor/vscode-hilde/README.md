# hilde-vscode

VS Code support for the hilde programming language.

## Installing

To install hilde-vscode first install the VSCode extension manager with

```sh
npm install
```

Then package the extension with

```sh
# NOTE: working directory must be `editor/vscode-hilde`
npm run build
```

This will generate a package file called `hilde-$VERSION.vsix`, which can be installed with

```sh
code --install-extension hilde-$VERSION.vsix
```

## Debugging

To start a debugging session open this folder in VSCode and press f5, or start debugging from the Run and Debug Menu.
Starting the debugger will open a child VSCode instance with the extension loaded.

To inspect the textmate scopes assigned run the VSCode command "Developer: Inspect Editor Tokens and Scopes" (`editor.action.inspectTMScopes`).

## Generating Syntax

The syntax is generated by stringify the export of `src/hilde.tmLanguage.ts`.
To re-generate the syntax run `src/generate-syntaxes.ts`.
The grammar follows the lexer of the compiler, `lib/Lexer.mll`; a keyword
or operator added there is added to `src/hilde.tmLanguage.ts` as well.

To run the typescript file:

```sh
npm run syntax
```

## Features

- Syntax highlighting of every token of the language.
- Indentation after `is`, `then`, `do`, `else` and `of`.
- Snippets
