# The name

HILDE stands for High-Integrity, Linear, Deterministic, Explicit.
Source files end in .hiq, High-Integrity Query.

Hilde is also named after a light grey cat. The name stayed because the
cat fits the language.

A walking cat puts each hind paw exactly into the print of its front paw.
Every step is placed once, never twice. That is what linear types do with
a value.

A cat cleans up after itself and leaves nothing behind. Hilde needs no
garbage collector, because every resource is released where it ends.

A cat checks before it jumps. The compiler checks before the program runs.

A cat is loud when something is wrong and will not be ignored. So are
Hilde's error messages.

Small, fast and independent, like the binaries Hilde produces.
