ONE page lent to eight tasks that render it at the same time, on eight workers (`env.txt`: `HILDE_TASK_THREADS=8`).  Every task renders the page 200 times and counts the renders that equal the expected text byte for byte; the programme prints the sum, 8 * 200 = 1600.  This is what 037 said it could not show: two tasks rendering the SAME data, and renders on several OS threads.  The page is lent through a lending scope, the way `043-regex/009` lends one `Regex`; 039 keeps the refusal of the same lend through a plain scope.  The checks run this suite under ThreadSanitizer, so a render that wrote shared state would be reported there.
