The length of a write span is read through a reference, spanWriteLength(&sp), so the span can be written to afterwards and a condition, the while and a requires, can ask for it.  &~sp hands the span to a function for the call and keeps it: fillAll writes 9 into all eight bytes, then the caller writes 5 into the last, then firstFour, whose requires reads the length, writes 1 to 4 into the first four.
