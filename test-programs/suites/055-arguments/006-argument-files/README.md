Argument files, as a programme: a word that begins with @ names a file whose words stand in its place, with quotes, a nested file and @@ for a literal @; after -- nothing is a file; a file that is not there, one that names itself and a quote that is never closed come back as errors with the place.  The programme writes its files in its own directory and removes them.  The unit tests of standard/src/Arguments.test.hiq hold the rest.
