The reading end of a pipe is watched for writing, and a write to it is tried.  It is reported writable exactly when the write is taken: Linux and macOS open a pipe's reading end for reading only and refuse the write, OpenBSD opens both ends for reading and writing and takes it.  Then the reading end is watched for reading and reports a byte written into the pipe.  Without a poller backend the first line is 0 and the test fails.
